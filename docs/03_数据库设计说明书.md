# PaperAgent V1 数据库设计说明书

本说明由 2026-11-11 `paper_agent` 数据库只读元数据生成；Alembic head 为 `4a2f0c781d66`。字段默认值以迁移和 ORM 为准；MySQL 是业务权威数据，SQLite Checkpointer 不是业务表。

主要关系：项目 → 运行尝试 → 审核决定/事件；Planner 生成记录 → 任务；Research 来源经关联表对应任务；Writing 稿件 → 单元、章节版本与调用账本；Review 报告 → 章节版本单元及调用账本。具体外键如下。
