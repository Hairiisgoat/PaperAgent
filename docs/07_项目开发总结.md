# PaperAgent V1 项目开发总结与后续待办

项目从项目 CRUD、版本化 LangGraph、人工审核、MySQL 执行与事件账本，迭代到真实 GLM Planner、Crossref Research、分段 Writing、章节版本、独立 Review 和文件导出。为解决生成截断，写作由整章改为分单元持久化；为避免重复计费，调用意图、call_id 和未知结果进入账本，无法确认时人工对账。LangGraph Checkpoint 与 MySQL 分工明确，但外部调用和两数据库无法 exactly-once。

论文证据从已批准摘要追溯；摘要字面匹配不能证明论据支持。真实四章和历史审查暴露证据不足及偏题风险，内容仍需用户检查。现有旧未知调用和人工对账需求被保留。导出使用当前版本和按首次引用编号，Review 为独立文件；旧快照不能导出为当前完整报告。

后续 UI/UX 待办：可靠小节结构与导航；更清晰的阅读、编辑、审查与版本关系；移动端体验；精细排版与有意义的微交互；项目列表和论文工作台进一步统一。工程待办：历史运行分页及完成稿发现、审查报告与来源元数据快照、可观测性及人工对账界面、跨进程事件与调度、认证与权限、源头证据质量和语义评测；不将这些标记为已完成。
