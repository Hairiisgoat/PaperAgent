# PaperAgent V1 项目需求与功能说明书

基准：2026-11-11 实际代码和运行结果。PaperAgent 面向本地使用的论文研究与写作，目标是协助组织工作，不提供学术真实性保证。

## 已实现

- 论文项目创建、分页查询、编辑、归档、恢复和软删除；尚无用户登录和用户级授权。当前课程论文写作要求引用格式，具体字段以 OpenAPI 为准。
- 真实 Planner 调用 GLM 生成服务端校验的任务；用户可部分或全部批准或拒绝。Research 使用 Crossref 公开元数据检索，按任务与主题词面排序并提供重复提示；人工审核资料。
- 批准资料后，Writing 分单元生成，正文、引用和来源证据保存在 MySQL；现有版本可阅读、按章修改、对比和恢复。Review 独立按章节版本生成结构化意见，不自动修改正文。
- 项目工作台可查看运行、审批、SSE、论文及审查，导出 Word、PDF 和符合条件的当前完整审查报告。

## 边界

模型的综合论述和审查仅供人工核验；摘要原文匹配不证明来源可靠、论点被充分支持或事实正确。当前全文存在引用集中及证据不足；Crossref 并非全文来源。章节结构或版本变化不自动修复其他章节。审查报告绑定版本，旧快照不能冒充当前报告。

当前仅支持本地单进程，未实现身份认证、多用户权限、分布式调度、完整学术事实核验或高校特定模板。Mock 图保留用于回归和历史兼容，真实 Planner 必须显式启动，不可将 Mock 数据视为真实文献。小节阅读导航暂未提供可靠数据；某些资料缺少摘要。
